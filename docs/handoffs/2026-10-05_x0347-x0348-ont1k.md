## Knowledge Capture

### Lessons Learned

The native filtering controls establish both the length boundary and the
quality scale. The resume checks reject a changed or dropped override before
Nextflow starts. Source-repair resume retains the saved override in its recovery
receipt and report. Full task completion still requires validating each real
sample's artifacts and scientific stage states.

### Gotchas

- Each run has its own launch and work directories. Re-poll the recorded live
  job before considering any restart. Current QC timeout policy is eight hours
  with one sixteen-hour retry.
- Use the reviewed task-local completion auditor.
  The historical auditor assumes 500 bp, and the October recovery driver
  requires annotation disabled. Both historical files remain unchanged.
  The new adapter still rejects within-execution retry traces and production
  runs with zero prokaryotic bins. Inspect real outputs before adapting those
  cases; never weaken a failing check just to obtain a pass.
- If a production run needs another allocation, inspect earlier GVClass source
  manifests as well as the latest launch receipt. The automatic auditor checks
  the latest launch. Rebuild the audit dependency only after inspecting its
  scheduler state; it may be canceled when an upstream job fails.
- Missing optional RNA/protein evidence may produce explicit pending or skipped
  gene-stage states. Do not relabel those as successful biological predictions.
- Restricted Claude reviewers cannot run Agentdash. Their actual review text
  is retained in JSONL; a lifecycle warning may replace the extracted final
  result. The main session reported their verified findings.
